## 快速开始

1. **双击 `index.html`** 就能看（纯静态，不需要服务器）。
   Firefox 那边用的是本地服务版：<http://127.0.0.1:8888/>（两个地址是同一份文件，

2. **设成别的浏览器的主页**：
   - Chrome / Edge：设置 → 外观（或「起始时」）→ 打开特定网页 → 填 `http://127.0.0.1:8888/`
     （或直接填 `file:///C:/Users/anzu/Documents/xin/xueran-home/index.html`）。
   - 本地服务起停见下面「为什么是 http://127.0.0.1」。

## 设成 Firefox 默认主页 + 新标签页（已经帮你配好了）

**主页和启动页**：Firefox 配置里写了 `user.js`

```
%APPDATA%\Mozilla\Firefox\Profiles\e05w21hi.default-release\user.js
  user_pref("browser.startup.homepage", "http://127.0.0.1:8888/");
  user_pref("browser.startup.page", 1);              // 1 = 启动时打开主页
  user_pref("extensions.autoDisableScopes", 0);      // 让下面那个侧载扩展自动启用
```

**新标签页**：Firefox 的新标签页只能由扩展用 `chrome_url_overrides` 顶替
（源码里 `AboutNewTab.newTabURL` 完全不读 pref，`browser.newtab.url` 早就删了），
所以装了 AMO 签名的 **New Tab Override 19.0.0**：XPI 放在配置目录的
`extensions\newtaboverride@agenedia.com.xpi`（签名版可以直接侧载，实测 `active: true`）。

> ⚠️ **重启 Firefox 后，第一次开新标签页会显示这个扩展的设置页**，
> 在「类型」里选 **「Firefox 主页」**（因为我们主页就是那个地址）保存一下，之后新标签页就是这个页面了。
> 一共就这一下点击，之后不用再管。不想装扩展的话，把 `extensions\newtaboverride@agenedia.com.xpi` 删掉即可。

### 为什么是 http://127.0.0.1 而不是 file://

- 那个扩展只接受 `http(s)://` 和 `moz-extension://`（源码 `Utils.uriRegex = /^(https?|moz-extension):\/\//i`），
  `file://` 会被它弹回设置页，所以本地起了个静态服务。
- 附带好处：配置（localStorage）挂在 `http://127.0.0.1:8888` 这个 origin 上，
  **整个项目文件夹随便挪位置，快捷方式和配色都不会丢**（`file://` 是按完整路径存的）。
- 服务由 `tools/serve.py` 提供，只监听 127.0.0.1，关了缓存，用 `pythonw` 启动所以没有黑框。
- **登录时自动启动**：启动文件夹里有个「许雪然主页服务.lnk」，登录后自动在 8888 起服务；
  万一页面打不开（比如服务没起来），双击项目里的 **`启动主页服务.cmd`** 就行。

### 想改回去 / 换别的

- 想自己在「设置 → 主页」里改：删掉 `user.js` 里对应那两行再重启 Firefox。
- 想彻底不要本地服务：删掉 `user.js`、`启动主页服务.lnk`、那个扩展 XPI，
  然后把主页换回 `file:///C:/Users/anzu/Documents/xin/xueran-home/index.html`（新标签页就只能保持空白页了）。

## 暗色模式（夜樱）

- 左下角齿轮上面多了个月亮/太阳按钮，点一下浅色 ⇄ 暗色；快捷键 **`D`** 也行。
- 设置抽屉里「🎨 主题」可以选 **樱花（浅色）/ 夜樱（暗色）/ 跟随系统**，选择会记住。
- 暗色不是简单反色：纸面变深紫玻璃、樱花方块变暗瓣+浅色描边、文字转浅粉，
  黑色 logo（GitHub 那类）会自动加一圈浅色描边，免得糊在深色花瓣上。
- 背景配色跟着主题走：浅色一套（樱花/粉雪/薄荷/晚霞/星夜），暗色一套（夜樱/暗粉/墨蓝/深紫/暖夜），
  切主题时如果当前配色不属于这套，会自动换成该主题的第一套。
- 页面声明了 `color-scheme: light dark`，这样 Chrome/Edge 的「自动深色模式」不会来乱反色
  （Firefox 本来就没这功能；实测这台机器上的 Edge 无视声明照样会反色，用 Firefox 打开不受影响）。
- 主题切换逻辑在 `js/app.js` 的 `applyTheme() / setTheme()`，样式在 `css/style.css` 末尾的
  `html[data-theme="dark"]` 那一段（用提权覆盖浅色规则，不动原来的代码）。

## 樱花方块

- 形状是用 SVG 花瓣遮罩（`--sakura`）套两层做出来的：外层粉色 = 描边，内层白粉 = 花瓣面。
- 大小 `--flower: clamp(78px, 10.2vh, 116px)`，矮窗口自动变小；1600×900 下是 92px 一朵。
- **每行数量按宽度自适应**：`grid-template-columns: repeat(auto-fill, minmax(var(--flower) + 16px, 1fr))`。
  实测 1920 → 8 个/行，1600 → 8 个/行，1366 → 7 个/行，手机 → 4 个/行。

## 快捷方式 & 自动抓 logo

- 点方块墙的「＋」樱花或标题栏的「＋ 添加」→ 填名称 + 网址即可；
  网址不写 `https://` 也能识别（`bilibili.com` → `https://bilibili.com/`）。
- 图标按这个顺序抓，谁先成功用谁：
  **iowen → favicon.im → DuckDuckGo → Google s2 → 站点自己的图标**。
- **本机 / 内网地址**（`127.0.0.1:3080`、`192.168.x.x:8080`、`nas.local` 之类）会**跳过第三方服务**
  （它们根本够不着你的内网），直接问站点自己，分三层找：
  1. 根目录最常见位置：`/favicon.ico` `/favicon.svg` `/favicon.png` `/apple-touch-icon.png`
     `/favicon-32x32.png` `/favicon-16x16.png` `/icon.svg` `/logo.png`；
  2. 各种前端模板的图标目录：`assets/favicons/…`（Vue/Vite 模板）、
     `static/img/icons/…`、`img/icons/…`、`icons/…`、`static/favicon.ico`、`assets/favicon.*`；
  3. **挂在子路径下的应用**：把上面那批路径再套 `ui/`、`web/`、`app/`、`static/`、`home/` 前缀
     —— 比如 `<base href="/ui/">` 的 SPA，图标其实在 `/ui/assets/favicons/favicon.ico`。
  探测是**并发分批**做的（限流 + 总超时），先跑第 1 层，不行才往外挖，所以正常的站点不会被拖慢。
  实测：`10.0.0.140` 抓到 `/ui/assets/favicons/favicon.ico`，`10.0.0.140:9999` 抓到
  `/static/img/icons/favicon-32x32.png`。
- 真找不到图标时，鼠标悬停那朵樱花会提示「没找到图标，点右上角 ✎ 可以手填一个」，
  在编辑框的「图标」栏里填 emoji 或图标地址都行。
- 网址输入会顺手做归一化：全角转半角（`127.0.0.1：3080` 的全角冒号也能认）、
  没写协议时本机/内网补 `http://`、其它补 `https://`。
- 这些服务对「没有图标的网站」会返回**假占位图**（实测 favicon.im=150×150、
  DuckDuckGo=48×48、Google=16×16），代码会按尺寸识别并丢掉，继续试下一个。
- 全都抓不到（比如域名不存在、断网）：花心就是一个**名称第一个字的圆形花蕊**
  （颜色由名称哈希决定，名字不变颜色不变；「哔哩哔哩」→「哔」、「GitHub」→「G」）。
- 抓到的图标缓存 7 天，失败的 24 小时内不重试；配置存在 `localStorage`（键 `xueran-home/config/v1`）。
- 想手写图标：编辑对话框里的「图标」栏可以填 emoji（🌙）或图片地址。
- 方块可以**拖动排序**；悬停樱花右上角出现 `✎`（编辑）和 `✕`（删除）；
  「✎ 整理」按钮会让所有方块一直显示这两个按钮。
  **没有「恢复默认快捷方式」按钮**，你自己加的不会被一键冲掉。

## 动效

- **樱花在整页最前面飘**：花瓣画布 `.fx` 是 `z-index:55`（比外框、看板娘、按钮都高），
  所以会从面板、Logo、立绘前面飘过去，不会藏在框后面；`pointer-events:none` 不影响点任何东西。
- **点鼠标 → 樱花炸开**：在点击的位置炸出 12~18 片花瓣，四散旋转再缓缓落下（0.9~1.4 秒消散）。
- 星光闪烁、鼠标划过留星屑；鼠标是粉色爱心光标。
- 立绘和 Q 版看板娘会轻轻浮动；看板娘点一下换一个 Q 版动作 + 冒一句台词。
- 按时间段换问候语（凌晨 / 早上 / 中午 / 下午 / 傍晚 / 晚上 / 深夜），立绘气泡台词跟着换，
  闲着每 24 秒还会自己说一句。
- 系统开了「减少动效」时自动关掉花瓣 / 星光 / 星屑 / 点击炸花（都归「樱花飘落」这一个开关）。

## 素材是怎么来的

`D:\XXR\键盘` 里的原图不是直接能用的（`logo.png` 是 2800×2800 的大留白图，
立绘尺寸巨大），所以有一个处理脚本：

```powershell
pwsh -File tools\prepare-assets.ps1          # 默认从 D:\XXR\键盘 读，输出到 assets\
```

它会：按 alpha 通道算包围盒 → 裁掉透明留白 → 等比缩放到合适尺寸 → 存成 PNG。

| 项目里的文件 | 来自 `D:\XXR\键盘` |
| --- | --- |
| `assets/logo.png` | `logo.png`（与 `img_6340_….png` 同图） |
| `assets/xueran-desk.png` | `桌子坐p.png`（透明底课桌坐姿） |
| `assets/chibi/chibi-q*.png` | `Q1/Q2/Q3/Q5/Q6/Q7/Q8/Q10.png`、`yaoshikou.png` |

想换素材：把图丢进 `assets/`，在设置里填路径；或者在 `js/app.js` 顶部的
`BG_PRESETS`（背景配色）、`CHIBI`（看板娘）、`DEFAULT_TILES`（初始快捷方式）里改。

## 快捷方式分类（樱花树枝分隔）

- 每条快捷方式有个 `cat` 字段；渲染时**按分类分组**，每组前面一行
  「樱花树枝 ── 分类名(数量) ── 樱花树枝」，树枝是可横向平铺的 SVG（粉枝 + 两朵小花 + 花苞），跟着主题换色。
- 默认分类：`常用 4` / `工具 2` / `摸鱼 2`；分类顺序 = 在列表里第一次出现的顺序，某类空了就自动消失。
- **改分类名**：先点右上角「✎ 整理」，再点分类名 → 原地变输入框 → 回车保存 / Esc 取消（留空＝未分类）。
  改完该分类下所有磁贴一起更新；改成已存在的名字＝两类合并。平时点分类名不会误改。
- **拖动换分类**：整个分类区域（图标 + 空白 + 树枝那行）都是放置目标。
  拖到某类空白处 → 归到该类并排到末尾；拖到某类某个磁贴旁边 → 归到该类并插到它的位置；
  同类内拖动只换顺序。
- **新建分类**两种方式：① 标题栏「＋ 分类」→ 建一个空分类并直接进改名状态（配好后往里拖磁贴）；
  ② **拖动磁贴时**，最后一类下面会滑出「拖到这里，自动新建一个分类」的虚线区，丢进去就自动建一个「新分类」并归进去。
  空分类会一直留着；整理模式下空分类名旁边有 ✕ 可以删掉它。
- **调分类顺序**：整理模式下，分类名旁边有 **▲ ▼**，点一下跟相邻分类换位置（顺序会存下来；「未分类」固定在最下面、不参与排序）。
- 新建的分类一定排在**最后**（不会跑到上面去）。
- 添加/编辑弹窗里有「分类」输入框 + 已有分类下拉候选；新增时默认沿用上一个分类。
- 你原来那些没分类的磁贴会先落在「未分类」里，拖一下就分好了。

- 自动抓 logo 需要联网；断网时就是名称第一个字的字块，联网后刷新会自动补上。
